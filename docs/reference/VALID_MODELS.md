# Known Model Names (Lowercase)

A vector of known model names available on CDS/ECMWF. The function
[`wass2s_download_cds()`](https://kiema97.github.io/AGRHYMET-WASS2SHydroR/reference/wass2s_download_cds.md)
will warn if a model not in this list is used, but will not stop to
allow for evolving model catalogs.

## Usage

``` r
VALID_MODELS
```

## Format

A character vector.
